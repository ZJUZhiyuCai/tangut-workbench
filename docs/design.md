# 界面约定

视觉方向：像一张安静、可长期使用的文献工作台，浅纸色、深墨色和单一赭红强调色；西夏字本身是视觉中心。

内容：先提供检索与字头列表，再显示义项、出处、研究关联；研究档案展示未释区与可证伪的假说，贡献页提供具体任务。工作界面不放营销封面或装饰性统计卡片。

交互：选中字头的底色过渡提示当前位置；详情切换时轻微淡入；折叠的研究记录按需展开。遵循 `prefers-reduced-motion`，键盘可以完成所有操作。

字体：中文与拉丁文字使用系统字体；西夏字使用随项目分发的 Noto Serif Tangut 2.170（OFL-1.1）。该版本未覆盖的 30 个 Unicode 17 字头显示码位提示，不伪造字形。编码索引仍完整保留。
