CONTRIBUTE

让下一条记录更可靠

从一条可定位、可核查的小贡献开始；保留不同意见，也保留被证据否定的过程。

  1. 补一条出处

    给出书名、版本、卷页、字头编号和可访问链接。说明你核对的是原页、转录还是他人的转引。

  2. 做一次复核

    核查一个词义、一处写本定位或一个竞争读法。认不出的地方留空，写清下一步需要什么证据。

  3. 提交一份小改动

    在 GitHub 提交 Issue 或 Pull Request，关联稳定的条目编号。数据校验通过后，仍需逐条审阅语言学判断。
